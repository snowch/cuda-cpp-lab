# CUDA lesson recordings

Copyright © 2026 Christopher Snow.

These twenty original three-scene recordings cover lessons 2–21. They use the
starter excerpt, execution relationships and hardware connection from
`content/v2-lesson-context.mjs`. Lesson 1 uses the first-kernel recording.

Follow the shared [recording production workflow](../README.md), using Common
Ground's pinned record-demo skill: Kokoro v1.0 ONNX CPU, `af_heart`, speed 1.0.
The former Flite fallback has been removed. The exporter requires generated
speech with matching provenance and renders native 4K frames.

Each lesson retains `recap.mp4`, `poster.jpg` and `captions.vtt`. Measured durations,
bytes, scene/cue times and voice provenance are in `content/v2-media.json`.
The transcript and speech derive from the same lesson text, with speech-only
forms for code notation. These are conceptual recaps, not recordings of GPU
execution or physical performance measurements. No supplied reference image
was copied or incorporated.
